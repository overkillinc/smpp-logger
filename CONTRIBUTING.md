Thank you for your interest in contributing to smpp-logger!

How to contribute
- Fork the repository and create a topic branch.
- Ensure code is formatted with gofmt and tests pass: `gofmt -w . && go test ./...`
- Open a pull request with a clear title and description of changes.

Code style
- Follow existing project conventions.
- Keep changes focused and document behavior changes.

Security
- Do not commit secrets or credentials. Use Kubernetes secrets or environment variables to store credentials.

Maintainers will review PRs and provide feedback. Thank you!
